An end-to-end machine learning project that predicts customer churn for a
telecom company. It walks through the complete data-science workflow —
exploratory data analysis, statistical hypothesis testing, data cleaning,
feature engineering, class-imbalance handling, and model training — using
Logistic Regression and Random Forest classifiers. Special emphasis is placed
on model interpretability and translating results into business
recommendations for a retention team.

**Stack:** Python · pandas · scikit-learn · imbalanced-learn · scipy · seaborn · matplotlib
**Skills demonstrated:** EDA · hypothesis testing · feature engineering ·
missing-value & outlier handling · class imbalance (SMOTE, class weights) ·
model evaluation (precision/recall/F1/ROC-AUC) · model interpretation
